
# Security Policy

## Scope

OpenTAF is an open-source reference framework for enterprise transformation, Agentic AI architecture, governance, and responsible AI.

This project is provided for educational and reference purposes. It is not certified for production deployment or regulatory compliance.

## Reporting a Vulnerability

If you discover a potential security vulnerability in OpenTAF, please report it privately.

**Do not disclose security vulnerabilities in public GitHub issues or discussions until they have been reviewed and addressed.**

Use GitHub's private vulnerability reporting feature, if enabled, or contact the repository maintainer privately through their GitHub profile:

https://github.com/vishalsandwar

Please include:

- A description of the potential vulnerability.
- The affected file, component, or version.
- Steps to reproduce the issue, if available.
- Potential impact and any suggested mitigation.

Do not include real customer data, credentials, access tokens, or other sensitive information in your report.

## Response

The maintainer will review reports and may request additional information to assess the issue and determine appropriate remediation.

This is a community-maintained project, and response or remediation timelines are not guaranteed.

## Supported Versions

Security fixes will generally be considered for the latest published version of OpenTAF.

## Responsible Use

Please use synthetic data for examples and testing. Do not use OpenTAF examples to process real customer or confidential data without conducting appropriate security, privacy, legal, and regulatory assessments.
