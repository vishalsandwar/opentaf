# Contributing to OpenTAF

Thank you for your interest in contributing to OpenTAF!

OpenTAF is an open-source reference framework for enterprise transformation, Agentic AI architecture, governance, and responsible AI. Contributions that improve its architecture, documentation, examples, testing, and governance practices are welcome.

## Ways to contribute

You can contribute by:

- Reporting bugs and suggesting improvements.
- Improving architecture and governance documentation.
- Adding examples using synthetic data.
- Proposing new agents, tools, or orchestration patterns.
- Improving tests, security, and responsible AI controls.

## Before submitting a contribution

1. Check existing issues and discussions to avoid duplicate work.
2. For significant changes, open an issue to discuss the proposed approach.
3. Keep contributions focused and explain the problem they solve.
4. Do not submit confidential, proprietary, personal, or employer-owned material.

- Improving architecture and governance documentation.
- Adding examples using synthetic data.
- Proposing new agents, tools, or orchestration patterns.
- Improving tests, security, and responsible AI controls.

## Before submitting a contribution

## Development setup

Follow the [Getting Started guide](docs/getting-started.md).

Install the project and test dependencies:

```bash
python -m pip install -e .
python -m pip install pytest
```

Run the test suite:

```bash
python -m pytest -q
```

## Pull request guidelines

Please ensure that:

- Changes are clearly described in the pull request.
- Relevant tests are added or updated.
- Existing tests pass.
- Documentation is updated where appropriate.
- No credentials, secrets, real customer data, or confidential information are included.

Keep pull requests focused and provide context for architectural or governance changes.

## Responsible AI and data

OpenTAF examples should use synthetic or appropriately anonymised data.

Contributions must not expose real customer records, confidential business information, credentials, or personal data.

AI agent examples should clearly describe their intended use, limitations, and relevant human oversight or governance controls.

## License

By submitting a contribution, you agree that your contributions will be licensed under the Apache License, Version 2.0, consistent with the project's license.

Thank you for helping make OpenTAF useful to the wider community!
